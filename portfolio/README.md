# Portfolio Engineering Projects

This directory contains independent, early-stage portfolio projects spanning LLM evaluation, agent benchmarking, red teaming, and backend infrastructure. Each README documents scope, limitations, and run instructions.

| Project | Focus |
|---|---|
| [Frontier LLM Evaluation Lab](frontier-llm-eval-lab/) | Transparent rubric scoring and reproducible comparisons |
| [Terminal-Bench 4.0 Experiment Harness](terminal-bench-4-harness/) | Harbor-based experiment workflow and result normalization |
| [LLM Red-Team Benchmark](llm-redteam-benchmark/) | Versioned adversarial and safety evaluation cases |
| [LLM Evaluation Runner API](evaluation-runner-api/) | Typed FastAPI job submission and status service |
| [Agent Trace Observability](agent-trace-observability/) | Agent span ingestion and trace summaries |

These are portfolio prototypes. Results, production readiness, and benchmark performance are not claimed until implemented, tested, and measured.
